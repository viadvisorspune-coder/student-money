# ResultHeadline

The answer to “what happens if I spend this?”: the money free to spend before and after, struck through and restated.

- **Consumer provides:** `before`, `after`, `caption` (what the spend was on) and `insight` (one sentence about the category it lands in).
- Use it once, at the top of the result screen. It states the change and never tells the student what to do — the choice stays theirs.
