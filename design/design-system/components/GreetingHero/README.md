# GreetingHero

The home-screen greeting card: an eyebrow, a large headline with one bold verdict, and a row of stat chips.

- **Consumer provides:** `eyebrow`, `children` (the headline, with the verdict wrapped in `<strong>`), and optional `leading`, `trailing` and `stats` nodes.
- Keep the headline under 60 characters and make the verdict honest and kind (“above average”, “on track”, “a little over budget”).
