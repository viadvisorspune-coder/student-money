# Button

A pill button with a text label for committing actions such as “Save bucket” or “Make notes on upcoming expenses”.

- **Consumer provides:** `children` (a verb first, in sentence case), an optional `icon` (placed after the label), `variant`, `full` and `onClick`.
- `dark` is the one primary action per view. `soft` is secondary. `danger` is for destructive actions, and its text colour warns without a red fill.
- Use IconButton when there is no label.
