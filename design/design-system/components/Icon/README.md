# Icon

Line icons on a 24px grid with a 1.75px stroke, drawn in `currentColor`.

- **Consumer provides:** `name` (one of the `IconName` values) and an optional `size` (default 20).
- Icons are decorative (`aria-hidden`). Put the accessible name on the button that wraps them.
- The glyphs are placeholders that match the reference. Replace them with a licensed set that uses the same stroke weight before release.
